# 执行手册

## 1. 锁定素材

读取当前 `confirmed-version/manifest.json`，只登记 current 且 QA passed 的规划图、
产品图、白模机位、最终渲染和细节图。不得从 delivery 或历史版本猜最新版。

## 2. 建立叙事

固定主顺序：

1. 封面；
2. 干净平面布局与规划讲解；
3. 用户产品/材质资产；
4. 分空间效果；
5. 细节与材料；
6. 结尾。

描线、四象限和红墙蓝窗只属于内部中间过程，默认不入册。

## 3. 分空间页面

每个空间至少选择一张正式效果图。若存在对应 white-model shot：

- 默认放 16%–28% 宽的小图；
- `shotId` 必须与效果图一致；
- 用“空间原图”或“机位依据”短标签；
- 用户明确不要时才关闭，并在 brief 记录。

重点空间可补产品图、材料或局部图；次要空间不为了凑页伪造细节。

## 4. 版式编排

先在 `page-specs.json` 为每页选 layoutMode 和理由，再写 HTML/CSS。超过 8 页至少
四种版式；同版式不连续超过两页。重点空间使用满版或大图，产品页使用比例板，
次要空间可用双图或图文反转。

## 5. QA

1. 浏览器逐页截图，检查文字溢出、图片裁切、inset 可读性和页面节奏。
2. 导出高清 PDF。
3. 运行 `pdf_quality_check.py` 生成页数、尺寸、色彩空间和全页预览。
4. 需要飞书发送时运行 `make_sendable_pdf.py`，但保留高清版。
5. 在线发布前把全部公开图改为 CDN URL；未确认公开不得发布。
