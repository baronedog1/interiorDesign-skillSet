# 单品照片到三维 HTML

负责照片到独立三维产品，以及已有产品的形体修改。输入是原始照片、用户要求、已有尺寸及确认过的模型；输出是单文件 HTML、可修改生成器/参数、原图对照和未解决项。只有明确要求时才交付独立 GLB；GLB 材质限制见[接口](data_contract.md)。整屋建模与 Blender 工程使用各自 Skill。

## 正式入口

在任务目录准备依赖，执行 `node product-modeling/scripts/build-workbench.mjs product.config.mjs model.html`，详见[运行说明](local_runtime.md)。网页只使用本包 `assets/workbench/` 工作台；保留选件、装配联动、显示/隔离、结构参数、位移、颜色/粗糙度、视图、分解、光影、截图、JSON 保存重开及 GLB 导入导出。

## 执行方式

本 Skill 默认由当前代理执行，不自动启动子代理。

## 高频数据来源

- 当前任务资料：原始照片、用户要求、已有尺寸、确认修改和当前模型；用于确定本件产品与本次交付范围。
- 生成器与观测参数：读取当前产品的源生成器、真实构造锚点、原图标注、相机与形体参数；接口和保存对象见[数据接口](data_contract.md)。
- 制作方法与运行证据：沿下方主线读取形体、校准、表面方法，并以最终 HTML 的同视角截图、交互和保存重开结果核对交付。

## 制作主线

1. **识别款式特征并拆件。** 实际打开原图，记录源图与裁剪；读[产品特征及截面连接](playbook/geometry.md)。将辨识度高的排列、留空、粗细、弧面、凹槽、端头、接缝绑定到真实几何和局部检查。不能把同数量、同外框当成同款。
2. **校准形体和相机。** 先整体骨架，再关键特征，再截面与连接。原图可见处追求同视角的形状比例一致；不可见处合理推测，不加无依据限制。多图共享同一几何，各自校准相机。读[校准方法](playbook/calibration.md)，先白模和局部对照，再处理材质。语义对应由读图判断；脚本计算投影、误差和数值优化，不冒称全自动理解。
3. **贴合材质颜色，再调光影。** 按[表面方法](playbook/surfaces.md)分组件核对原图颜色、纹样方向、尺度和粗糙度，最后调整光源、曝光和接触阴影。纹理吻合不能代替几何；默认交付带材质成品。
4. **构建并复核真实文件。** 按[接口](data_contract.md)接入生成器，实际用 `file://` 打开最终 HTML，检查模型可见、无外部请求、交互与保存重开。执行环境若拦截导航，只记录这一项受阻，继续可做的检查；不能用页面注入代替本地打开通过。形体与运行结果分别记录，详见[交付品质](expected_outcome/expected_outcome.md)。

锚点必须来自生成器的真实构造点/网格，不移动原图标注迎合模型。整体轮廓分数不能抵消关键特征错位；没有通用的“完美通过”像素门槛。修改几何后从同版模型重算证据，禁止修截图掩盖差异。

## 交付与范围

交付成品 HTML、源生成器/观测/参数、原图/白模/成品同视角对照及限制说明；用户要求 Skill 包时附本版本。最终证据来自实际 HTML，不沿用旧截图或照片生成的白模示意。平台上传沿用已有授权与平台 Skill，本技能本身不访问凭据或生产环境。

遵从用户指定设备，建模和浏览器使用该设备现有资源约束；同一产品单一写入者，拟合有迭代/时间边界，结束关闭本任务浏览器。唯一活跃入口为 `product-modeling`；旧同用途副本退出发现目录，回滚快照在任务归档。人读[说明书](SKILL_MANUAL.pdf)。
