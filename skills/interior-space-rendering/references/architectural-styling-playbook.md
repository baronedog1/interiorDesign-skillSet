# 建筑风格化总 Playbook

## 决策顺序

1. 先读用户风格、空间功能和主视觉面。
2. 再读 scene map 中真实墙、开口、天花、阳台围护和组件槽位。
3. 先确定不可变几何，再确定表面、灯具、门扇状态和配饰。
4. 公共空间可有完整的墙顶灯饰组合；小空间按功能克制处理，不机械复制客厅配置。

## 分层

- **结构层**：墙、洞口、天花体积、阳台围护。渲染不改。
- **构造表面层**：墙地顶饰面、窗框玻璃、门扇表面。按风格调整。
- **固定产品层**：柜体、洁具、灶具、灯具。只按封闭世界 JSON 槽位重建，Q2 家具图仅供人工核对，绝不作为绘图输入或形状事实源。
- **软装层**：活动家具、窗帘、地毯、挂画、植物和摆件。按槽位与净空布置。

## 风格映射

每个处理项写可观察的材质、比例和构造，不只写风格名。例如现代新中式可写“浅暖矿物漆、克制木饰面、窄框玻璃、低饱和织物、少量书画”，避免自动生成博古架、繁复格栅或满墙符号。

## 结构回流

若设计需要跌级吊顶、新隔断、缩窗洞、增加门、改变阳台围护，先在对应 HTML/Blender/CAD 后端生成新 revision。新 revision accepted 后重新找机位；旧 scene map 自动失效。
