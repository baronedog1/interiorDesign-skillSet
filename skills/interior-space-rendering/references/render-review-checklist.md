# 渲染复核清单

按顺序检查，前一层失败时不继续用审美掩盖：

1. **封闭集合**：required 房间、连接、结构、槽位逐项完整；六类 unexpected 列表全空。
2. **结构**：墙、门、窗、洞口、层高、阳台和房间比例与源图一致；未登记门窗绝不出现。
3. **外部边界**：入户门等 exterior connection 只采用 allowed depiction，远端不得变成另一个室内空间。
4. **相机**：视平线、消失点、焦距观感、裁切、左右关系一致，无镜像或扩图。
5. **布局**：全部可见家具和柜体的类别、数量、位置、朝向、通道一致；槽位为空时不得出现功能对象。
6. **替换**：每个槽位对象都有同品类资产或诚实通用配方；目标尺寸不超过允许包络。
7. **新增项**：只属于有限非结构白名单，不创造空间、开口、槽位或堵塞净空。
8. **硬装**：没有新增隔断、吊顶体积、门窗、柜墙或其它未授权构造。
9. **光线**：主光来源成立，暗部和窗面均有细节，无黑蒙或过曝。
10. **风格**：目标风格清楚，但不以单一颜色覆盖全部材质层次。
11. **产品完整性**：沙发、柜体、桌椅等有真实构件和材料细节，不是简单上色方盒。
12. **来源关系**：结果唯一绑定当前 `floorplanId/shotId/sourceImage`。

复核证据必须覆盖 scene map 的完整 ID 集合。某个墙段、槽位或开口一旦超差，只能拒绝并重做候选，不能删除该测量、替换成更容易的对应点或改用中位数通过。

任一 1–8 或 11 项失败即 `rejected`。9–10 项可在不改变不可变事实的前提下重做。
