# 不可变空间合同

## 永远不可由渲染改变

- 房间长宽高、墙长厚高、空间边界和相邻关系；
- 门、窗、洞口、柱、阳台、台阶和固定通道的位置与数量；
- 相机位置、目标、焦距、FOV、画幅、裁切、视平线、消失点和左右方向；
- 家具/柜体的类别、数量、项目位置、朝向、功能关系和分配给它的最大占地包络；
- 源截图中真实可见或隐藏的结构状态。
- `closedWorldView.required` 的完整对象集合及 `boundaryTerminations` 的室内/室外属性。

效果图不得扩房、缩房、拉长墙、镜像、移窗、补门、改开口、在外部边界后续画室内空间，或增加任何未登记功能对象。

## 可变化

- 墙地顶和家具的表面材质、纹理与颜色；
- 符合真实开口方向的自然光、灯光氛围和曝光；
- 仅限 `closedWorldView.additionPolicy.allowedClasses` 的非结构饰品、挂画、灯饰、吊顶表面细节和软装配饰；
- 家具/柜体产品外观替换；目标尺寸只能位于记录的 `allowedEnvelope` 内。

## 家具替换锚点

替换家具前先选锚点：

- `center`：中心不动，尺寸向两侧等量变化；
- `left-edge/right-edge`：一侧贴原锚点，尺寸只向另一侧变化；
- `front-edge/back-edge`：沿使用面或墙侧保持；
- 结构锚点：与墙、柜端、窗边等明确 ID 对齐。

示例：3.0m 沙发换成 2.5m，中心锚定时两侧各露 0.25m 原墙；左边锚定时右侧露 0.5m。墙长、相机和其它家具不动。

源白模的简单方盒不是最终产品外观。其类别、位置、方向和包络受保护，但靠背、扶手、腿脚、坐垫、柜门、拉手和材料必须由 `assetMatch` 细化。替换后仍需满足原通道、边界和碰撞关系。

## 硬装边界

材料替换不等于结构改造。木饰面、涂料和墙纸可覆盖现有面；新增厚墙板、吊顶跌级、隔断、壁炉体、整墙柜或开洞属于结构/固定布局变化，必须先回到平面规划和当前 HTML/Blender/CAD 建模后端形成新版本。
