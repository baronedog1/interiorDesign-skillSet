# Furniture Detail Story Video Template

Use when the project contains confirmed replacement furniture or a strong product/detail highlight.

- Recommended duration: 12-24 seconds.
- Image count: 3-6, including main room view and close-up detail images.
- Order: full room context -> furniture close-up -> material/edge/detail -> lifestyle moment -> return to room context.
- Motion: dolly in, orbit around object, slow rack-focus style transition.
- AI character: optional; use seated/standing scale reference only when it helps the user understand size.
- Prompt focus: preserve furniture category, fabric/wood/metal details, scale and spatial relation.
