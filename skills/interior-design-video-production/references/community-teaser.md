# Community Teaser Video Template

Use when publishing a short community teaser for a design case.

- Recommended duration: 8-15 seconds.
- Image count: 3-5 strongest images.
- Order: cover hero -> strongest detail -> second space -> closing brand/solution feel.
- Motion: clean cuts or fast but smooth push-ins; avoid overcomplicated transitions.
- AI character: normally off.
- Prompt focus: visual impact, consistent palette, premium editorial rhythm.
