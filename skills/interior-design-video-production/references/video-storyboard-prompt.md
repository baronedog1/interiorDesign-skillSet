# 视频分镜原生绘图提示词

以下模板只负责生成导演沟通用分镜草图，不生成户型图、效果图或最终视频。

```text
基于所附当前确认版空间图片和分镜计划，绘制一张中文粗线稿 storyboard sheet。
每格包含：时间码、镜头号、人物站位、焦点对象、相机运动箭头和转场提示。
保持当前空间结构与家具位置，不引入图片中不存在的房间或产品。
同一镜头的起点、终点和焦点必须与 storyboardPanels[] 一致。
全部文字使用简体中文；这是导演沟通草图，不追求写实成片质感，不冒充最终效果图。
```

生成后由 Agent 对照 `storyboardPanels[]` 逐格复核。分镜图片只有通过
`idk-canvas-ingest-agent` 上传并取得 HTTPS URL 后，才允许进入 Seedance
dry-run 或真实生成请求。
