# Whole House Walkthrough Video Template

Use when the customer needs a complete interior design walkthrough after images are approved.

- Recommended duration: 30-60 seconds.
- Image count: 8-15, ordered by real walking path.
- Default pacing: 3-4 seconds per key image.
- Order: entrance -> living/dining -> balcony or feature wall -> kitchen -> master bedroom -> children/elder room -> study -> bathroom/utility -> closing hero.
- Motion: slow forward walk, gentle pan, smooth room-to-room transition where adjacent spaces connect.
- AI character: off by default; add only if user wants lifestyle presence.
- Prompt focus: keep same design style, material continuity, warm realistic light, no layout changes.
