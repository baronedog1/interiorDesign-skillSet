# Material Detail Story Video Template

Use when material, lighting or joinery details are the value proposition.

- Recommended duration: 16-28 seconds.
- Image count: 4-7, combining main render and detail images.
- Order: main space -> material close-up -> lighting reflection -> joinery/hardware -> return to full space.
- Motion: macro push-in, small lateral slide, slow reveal.
- AI character: off unless used as scale reference.
- Prompt focus: tactile surface, light falloff, realistic material response, no fake brand marks.
