# Source Model Method

## 代码负责

- 绑定源图、证据、语义判断和几何的 SHA-256。
- 对低对比或有轻微透视的拍照图生成可逆的旋转、透视校正、对比度增强与逐空间
  局部裁图；每张辅助图保存互逆 `3x3` 变换并完成四角加中心五点往返，再把坐标
  反算回唯一原图坐标系。任何可读颜色、背景和对比度的源图先由固定
  `grayscale-local-contrast-union-v1` 归一化为黑白线证据；二值化、Hough 和 OCR
  只定位候选，不决定候选语义或整张图是否可用。归一化不构成输入门禁，也不得由案例
  自定义；它只用于检验候选输出是否对齐源图可见线。
- 把本轮候选路径确定性回绘到源图，候选叠图与墙体编译共用同一坐标；分别输出
  墙/开口、房名/分界、对象三组干净图及编号复核图。
- 从 `faceA/faceB` 唯一生成墙带。
- 从冻结物理开口候选和唯一语义分类生成窗、门、移门、源图可见通道与玻璃开口。
- 从源图房名证据和两端墙锚点确定性生成无实体墨线的开放功能分界；该分界不进入墙、门或窗层。
- 测量墙两侧与源图墨线的距离。
- 从墙带、开口闭合线、开放分界和空间种子生成净室内、空间边界、面积、墙邻接和连接两侧。
- 拒绝空间种子合并、种子与不可变源房名锚点分离、无人认领区域、同空间假墙、
  错误连接端点和无通行开口空间。
- 封装同一 `floorplanId` 的结构、组件和图片。

## Agent 负责

- 区分墙、柜体、家具、门扇、尺寸线和文字。
- 查看三组干净候选叠图及编号复核图并逐条确认是否贴合；外轮廓必须沿内外两条墙边顺时针连续走完，斜切、外凸、凹口和任意角度转折不得矩形化。Agent 只判断语义，不得凭目测另写一套近似坐标。
- 同时查看原图、可追溯局部增强图和候选回绘；只有具体候选仍无法唯一解释时才写
  `unresolved`，并记录候选 ID、原图坐标、局部裁图、竞争解释和缺失证据。禁止把
  单一阈值失败或一句“图片不清晰”作为整体停止理由。
- 判断遮挡墙，但必须记录独立证据。
- 逐房间顺时针检查墙、源开口、窗、门和通道。
- 对每个有物理证据的门、通道、移门和玻璃写明两个相连空间，并引用同一
  `sourceOpeningId`；不能只保留一个没有空间端点的门符号，也不能另写线段。
- 为每个真实空间选一个明确位于净地面的种子，并分类为 `enclosed/open-zone/circulation/attached`。源房名锚点只证明文字位置，不是可移动的拓扑控制点；独立种子可以选同房间内其它净地面，但编译后必须与源房名落在同一连通区域。二者分离时修边界，不改房名。
- 判断客厅、餐厅、阳台、厨房之间是否确有功能分界；有则先确认两个独立源房名和两端墙锚点，再登记 `sourceDividerId`。实际可直接穿行写 `traversal=open-passage`，仅有功能边界但被柜侧或设备阻隔写 `boundary-only`；代码始终生成同线非墙分界，只为前者生成开放连接。无分界则保持一个空间。无实体墨线的分界禁止写入 `openingCandidates[]`。
- 对 `enclosed` 空间的多个通行开口逐项复核，不能仅写笼统 `passed`。
- 查看源图叠加图，确认没有漏墙、假墙和错误空间。
- 识别曲线、凹口、地垫和有效内部线。
- 从床头、枕头、椅背、沙发靠背、电视朝向和桌椅关系等源图符号确定世界朝向。源模型
  顶层固定写 `orientationAngleUnit: "degrees"`，并按度数填写 `rotationY`；不允许无单位
  数字、对象级混合单位或按数值大小推断。优先用 `front=+Z`、`back/headboard=-Z` 的规范局部轴；兼容的其它
  局部轴表达会由编译器在不改变世界朝向的前提下归一化。不得用包围盒长边代替方向，
  也不得预先补偿下游资产轴或编译器行为。编译器只在 handoff 边界把度数转换一次为弧度。
- 曲线、圆形和有机轮廓使用不少于 12 个源图采样点；代码从对象局部轴归一化轮廓计算曲线边比例、圆度、凹凸性、`shapeClass` 和左右手性。源模型不填写这些派生字段，也不能用声明值覆盖编译结果。
- `enclosed` 空间必须在源开口台账中直接连接至少一个 `door` 或 `sliding-door`；仅有开放分界或 `open-passage` 时，应按源图修正空间分类或开口事实，不能伪造门。

## 为什么只保留一次检查

错误图通常来自候选证据不完整或语义分类错误。重复计算同一组错误坐标不会修复源事实，只会拖慢流程。正式链路因此只有：

`源像素描点 -> 同源候选叠图 -> Agent 分类 -> 确定性编译 -> 一次源模型检查 -> Agent 最终看图 -> handoff`

检查失败只回到对应事实层修正，不新增例外、兼容或降级路径。
