# 四象限合同

1. 第一象限：原始户型图，不修改。
2. 第二象限：完整保留第一象限原图的颜色和像素，不淡化、不擦除、不替换底图。在其上叠加第一阶段全部分类轮廓；空间使用半透明黄色块和黄色虚线边界，黄色块只能位于红墙内侧。空间块和虚线只来自拓扑编译器生成的 `spaces[]`，不能手画；客厅与阳台等开放功能分界只显示黄色虚线，不进入红墙。红色双边墙、蓝窗、琥珀门、绿活动家具、紫固定构件、灰其它有效线必须贴合全部可见且非文字的有意义线。
3. 第三象限：白底墙窗框架。墙只读取唯一 `wall-geometry.json`，窗只读取源开口候选及其 `window` 分类；authored spec 仅绑定宿主墙和高度属性。拓扑编译后两者物化为同一 compiled spec。墙带必须是红色闭合双边轮廓，窗为蓝色；门洞与通道留空；不得显示家具、柜体、空间区域、名称、尺寸或原图底图。
4. 第四象限：白底纯描线组合，只显示第三象限墙窗框架、琥珀门线、绿色活动家具和紫色柜体设备的全部外轮廓与内部细节；不得显示空间区域、空间名称、说明文字或原图底图。

第三象限是规划和三个户型建模后端共同读取的硬结构来源；第二象限提供源图、区域与分类的同坐标证据；第四象限是完整规划描线结果。第二象限黄色空间并集必须等于编译器得到的全部净室内面积，且每个像素只归属一个空间。任何修改先回到源墙、开口、空间种子或开放分界再重新编译；禁止直接修最终图片或手改房间多边形。
