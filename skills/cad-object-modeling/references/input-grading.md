# 输入证据等级

等级只描述能否严格约束三维，不评价照片清晰度或建模者能力。

## A 级：可严格验收

同时满足：

- 至少三个互相正交的已标定视图，`normalAxis` 覆盖 X/Y/Z；
- 每个视图明确正交投影，或透视已完成相机标定并重采样为登记了可逆矩阵的正交证据；
- X/Y/Z 总尺寸均有明确标注或用户确认；
- 视图之间同一组件、特征和尺寸不冲突。

A 级允许在全部门禁通过且没有未解决假设时交付 `accepted`。

## B 级：可建模、需标推断

至少一个已标定正交视图和一个明确尺寸，但缺少其它轴视图、背面、底面或内部。严格匹配所有已提供面；不可见几何按保守假设构建并逐条登记。默认交付 `provisional`，用户补充证据或逐项确认后可重新评级。

## C 级：先补尺度或相机

只有未标定透视图、渲染图，或没有任何尺度。可以生成概念 CAD 简报和待确认组件拆分，但不能声称尺寸复刻。优先从以下任选其一解除阻塞：

- 用户给一个总尺寸；
- 图中存在可信已知尺寸物；
- 提供正交俯/正/侧视；
- 求解相机内外参并登记误差。

涉及配合、安全、承载或采购接口时，C 级必须停止并问一个聚焦问题。

## 冲突优先级

明确数字标注 > 用户本轮文字确认 > 同比例工程图 > 已标定正交像素 > 已求解透视 > 未标定渲染图。两个同级明确事实冲突时禁止静默择一。
