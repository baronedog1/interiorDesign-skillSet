# 描线到受管资产

1. `semantic` 只保留绿色活动家具或紫色固定/安装对象的编辑含义，不作为真实资产查找的隔离墙。
2. 在全受管库按规范化后的 `functionalClass` 匹配；仅 `area-rug/floor-rug/carpet -> rug` 属于登记同义关系，不存在跨功能类别替代。
3. 形态必须相同，尺寸必须落在资产允许缩放范围；普通家具等比缩放，审核柜体才可分轴。
4. 床、沙发、椅子、柜体等有方向对象必须使用已登记校准轴。源图世界方向与资产局部轴共同决定模型 yaw。
5. 多个合格候选按尺寸拟合、文字/风格证据、方向校准和稳定 ID 排序，直接选择第一名。
6. 无合格候选时报告 `ASSET_MATCH_GAP`，通过正式联网检索、许可核对、尺寸/轴标定和浏览器验收后补入中央库；禁止生成色块或轮廓替身。

来源轮廓决定占地、位置与计划朝向；公共模型决定三维外观。两者不能互相反写。
