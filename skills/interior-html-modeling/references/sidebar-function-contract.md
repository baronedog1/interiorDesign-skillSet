# 侧栏与交互合同

## 布局

- 顶栏只放撤销、重做、平面/三维、空间筛选、标注、量尺和二维依据。
- 默认进入近顶视的三维 Orbit，不使用“先正俯视、首次拖动再突然切三维”的模式。左键围绕真实户型中心连续旋转，右键只平移整幅画布，中键/滚轮缩放；不同屏幕首次打开都按画布可用区域适配完整 `floorBoundary`，相机、灯光和辅助线不参与中心计算。
- `空间筛选` 是基于 `rooms[].id` 的多选菜单。选择集合同时过滤画布、四页对象列表和已保存机位；不得为每个模块维护独立筛选状态。全选显示全户型地板，清空也保留全户型地板；单选/多选始终显示已选房间地板。
- 二维依据默认隐藏；中间画布占主要空间。
- 右侧桌面宽度约 360px，移动端移到画布下方。
- 卡片圆角不超过 8px；命令优先使用紧凑方形图标按钮和悬停说明。

## 四页

1. `结构`
   - 第一块固定为“快速结构工具”，一行恰好六个无文字 SVG 扁平按钮：选择、调整墙、添加墙、加窗、加门、删除。图形必须表达动作，悬停和键盘聚焦时显示短说明；`aria-label` 必须存在。确认修订保留为独立流程按钮，不占这六格。结构页默认隐藏且不拾取组件；顶栏可临时显示家具，但仍不拾取，只有用户手动进入“组件”页后才允许选择家具。
   - 结构首屏的组件懒加载与自检必须一致：数据合同持续验证，依赖运行时网格的占地和代理检查仅在组件已加载后执行；不得因未加载产生假失败，也不得为自检强制加载家具。
   - 列出空间筛选范围内的墙、门和窗；长墙按与房间多边形边界的真实接触区间裁切显示，不得跨出所选空间。
   - 墙、门窗列表与检查器展示 handoff 来源、尺寸、宿主和相邻空间。双击只锁定对象；墙列表末尾独立“正视”按钮才进入正视。墙厚数字输入跟随当前墙出现在对象标题下方的顶部快捷区，提交时先过平行墙、门窗、家具碰撞，拒绝则保留原厚度。只有选择调整墙后，墙高中线才显示恰好两个端点圆点；可视圆点约 30px，实际鼠标命中区至少 52px 并随屏幕和相机缩放，墙身不触发。拖哪个圆点就只移动哪个端点，另一端不变；向外是拉长、向内是拉短，8cm 内磁吸。同一直线墙段不得产生正长度重叠；只有接近 90° 的墙体中心线可以相交，斜向穿越必须阻止，垂直交点也不得落在门窗洞口内。门窗左键沿墙按厘米移动，同墙洞口必须保持至少 8cm 净距且不得跨越其它墙体。
   - 添加墙自动进入同一模型的二维俯视，采用按住拖动的两点直墙与默认正交吸附；边界内外都允许绘制。新增对象明确标记 `human-in-editor`，不得伪装成原图识别事实。
   - 删除墙时只级联该墙宿主的门窗，并清理摄像头显隐引用；全部操作进入撤销栈。墙改窗保留宿主墙语义，通过接近满宽的真实窗洞实现，不把墙替换成一块无宿主玻璃板。
   - 每次合法编辑写入 `structure-edit-patch.v2`；点击确认导出唯一 `human-coauthoring-revision.v1`。只有确认后的 revision 才交给第一 Skill 编译新的 accepted handoff，供三后端共用。
2. `组件`
   - 顶部只保留选择、新增、显隐、删除四个 SVG 快捷按钮；删除在选择组件后立即可用，检查器底部不得再出现第二个删除入口。
   - 只列空间筛选范围内仍存在的绿色/紫色描线一对一匹配组件；
   - 显示来源、`sourceTraceId`、组件 ID、位置、旋转和等比例缩放；
   - 不提供临时新增或跨库替换入口；每一项提供隐藏/显示、顺时针旋转 `90°`、复位和显式删除图标，并保留槽位与已删除 `sourceTraceId` 审计。
   - 单击组件即进入键盘移动状态；方向键步进移动，`Shift` 加速；画布按住组件可直接拖动。双击组件显示一个中心移动点和四个角点；拖任一角点按屏幕中心半径统一改变宽、深、高，二维和三维行为相同，不允许单轴拉坏家具。每个偏离 `source*` 的编辑候选先按真实源轮廓和高度做边界、墙体、真实开口、非地毯组件碰撞和 `relationHints` 引用校验；允许边界相接，不允许面积穿透，非法位置保留在上一合法坐标。源图已有的贴合或嵌套关系作为冻结基线，只允许保持、退出或减轻，不允许新增或加深；动线合规仍由后续 Skill 复算。
3. `场景`
   - 顶部用 `光 / 摄像头` 两个同级按钮切换；
   - 两类对象共用紧凑命令条、位置/焦点三轴、滑杆和数字输入；
   - 光源列表只显示当前灯，按顺序自动编号，不输入名称；
   - 摄像头检查器顺序固定为焦点、位置、镜头；
   - 镜头区提供 16/24/35/50mm、焦距和 FOV，并用半透明短文解释各字段；全部镜头保持直线透视，不提供鱼眼或桶形曲度；
   - 墙面吸附、聚焦空间、进入/退出机位、截图、恢复和删除使用同一行方形图标按钮；
   - `已保存机位` 必须在当前摄像头全部参数之后，不能抢占参数区顶部；
   - 每个机位条目显示顺序、空间、角色、焦距，以及局部遮挡和逐机位打光标记；
   - 点击机位临时套入当前摄像头和灯光，再次点击同一机位无损恢复；
   - 场景设置可导出为 `scene-rig.json`，临时预览参数不得混入导出。
4. `图层`
   - 墙、窗和玻璃、紫色固定构件、绿色活动家具、天花板、吊灯、摄像机、灯光、网格、空间和尺寸标注。天花板高度读取当前墙顶并默认隐藏；吊灯本体可独立隐藏，但真实灯光仍由场景页控制。

单击和双击都由当前页决定拾取类型，防止误触；双击只锁定当前编辑域内的对象，不自动切页或跳正视。所有对象手势在捕获阶段归编辑器，只有从空白画布开始的手势才归 Orbit；两次点击之间的鼠标抖动不得移动相机，双击必须复用稳定的点击目标。场景对象使用本体拾取代理，单击、双击和拖动共享同一目标解析；不得依赖点击重叠时的偶然射线顺序。

## 摄像头交互

- 单击本体即选择；按住本体或中心点做水平移动；拖动红/绿/蓝轴做单轴移动。二维和自由三维行为一致。
- 双击摄像头或光源进入位置编辑，并显示对应操纵轴；双击摄像头同时开启左上角实时预览，但不得自动切入固定视角。
- 固定视角只由显式“进入视角”或已保存机位触发；固定视角中，方向键平移，`W/S` 或滚轮前后移动，双击空白画布改变焦点，镜头参数继续生效。
- 只有画布 Orbit 拖动才退出固定视角；退出提示必须明确，且不得自动改写原机位。
- `辅助线` 只隐藏三轴和焦点线，摄像头与光源本体仍可见。
- 墙面吸附和聚焦空间计算只在提交时执行，连续拖动期间不得重建场景。
- 非固定视角点击空白会取消对象选择；仅在无选择状态下，方向键平移整个画布焦点且保持当前观察方向。

## 二维机位与局部遮挡

- 场景摄像头可在二维平面或自由三维中编辑；进入任一视图先以户型中心为 Orbit 焦点。平面主画布显示相机位置、目标和视锥，左上角独立 16:9 画面持续显示同一相机实时预览，右下角手柄可调整显示大小。
- 切换平面、三维或右栏页签不得关闭预览；相机和灯光拖动必须改变预览 frame count 与像素签名。
- 正式 shot 固定保持全屋与连通空间，只应用第三个 Skill 写入且有证据的 `hiddenElementIds`。
- `preserveElementIds`、`mustShowElements` 和背景房间优先保留；HTML 不自动扩大遮挡范围。
- 关闭、切换机位、撤销或恢复后，全部对象重新可见，模型数量不变。

## 白模、标注与量尺

- 顶栏只提供结构“白模/水泥”外观切换，不提供任意材质颜色选择器；水泥只改变结构皮肤。
- 房间虚线边界、名称、面积、悬停高亮和外部总尺寸统一受标注开关控制，默认隐藏；全部直接读取 `rooms[]`，不建立第二套热区数据。
- 外部总尺寸字号明显高于房间标签。
- 两点量尺显示三位小数米制距离，可清除，不修改模型。

## 失败行为

非法的新窗洞、墙尺寸或组件位置不写入模型。结构编辑若导致家具、机位或关系提示需要复核，可保留结构草稿并显示建议；确认导出时必须把建议带入 revision。组件越界、穿墙或互相穿模时仍回滚到上一合法状态并说明第一项原因；不得自动替换或静默删除无关对象。
