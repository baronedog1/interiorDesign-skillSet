# 标注与两点量尺

## 被动标注

被动标注包括空间虚线边界、空间名称、净面积和户型外部总宽/总深。它们必须共用 `layers.annotations`：

- 默认 `false`，首次打开模型不显示任何被动文字标注。
- 顶部 `Aa` 按钮与图层页使用同一状态；任一入口切换后另一入口同步。
- 标注开关是纯显示操作，直接刷新边界、标签和按钮状态；不得进入墙体、门窗或组件
  的几何修改事务，也不得因无关的摆放问题回滚。
- 开启后，每个空间按同一 `rooms[].polygon` 绘制闭合虚线边界，名称和 `areaM2` 投影到 `labelPosition`；外部总尺寸沿画布外缘显示。
- 鼠标进入某个空间时，使用平面射线点与同一 polygon 判断，只高亮该空间边界、标签和半透明地面；不得从截图识别区域，也不得维护单独热区。
- 空间筛选和焦点隔离只显示当前可见空间的边界与标签；移出画布、关闭标注或进入操作工具时清除高亮。
- 外部总尺寸字号必须大于房间标签，桌面目标不低于 14px，移动端不低于 12px。
- capture 模式始终隐藏被动标注，避免把编辑说明带入机位截图。

标注只改变显示，不改变墙、窗、房间或组件数据。

## 两点量尺

量尺是主动工具，不属于被动标注：

1. 点击量尺按钮进入测量模式。
2. 只接受 `floorBoundary` 内的平面点。
3. 第一次点击记录 A，第二次点击记录 B。
4. 用米制平面坐标计算欧氏距离，显示三位小数，并画出端点和连线。
5. 第三次点击开始下一组测量；清除按钮删除当前量尺；`Esc` 清除并退出。
6. 量尺结果不写回结构数据，不自动修改墙、窗或组件尺寸。

程序化接口：

```js
editor.setMeasurementMode(true);
editor.measureBetween([1, 1], [4, 5]); // 5.000 m
editor.clearMeasurement();
```

## 验收

- 初始被动标注隐藏。
- 显示后每个空间的边界、名称、面积和总尺寸均出现，关闭后全部消失。
- 在每个空间内移动鼠标，只高亮命中的 `roomId`；边界点、面积数字与 `structure-data.json` 一致。
- `measureBetween([1,1],[4,5])` 返回 5.000m 的可见结果。
- 越过户型边界的测量点被拒绝并给出状态说明。
- 桌面和 390px 窄屏不发生工具栏、尺寸文字或侧栏遮挡。
