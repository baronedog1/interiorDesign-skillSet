# 奶油自然 / Cream Natural

这是一套本包实现的可执行设计配方，不代表该风格的唯一历史定义。运行数据唯一来源：`catalog/styles.json` 中 `cream`。

## 主题

温润、松弛、圆弧与低对比；不是所有表面统一白色。

## 家具形状

厚软包模块沙发、弧形床头、圆角餐椅、椭圆石材台面。

## 材料

米白矿物漆、浅橡木、亚麻圈绒、哑光洞石、少量香槟金属。

## 细节

柜门细分缝，条纹圆柱支脚，波褶帘和陶器保持克制。

## 打灯

3000K柔和人工光，适中环境亮度；保留地面与天花明暗。

## 避免

避免全局泛黄、所有材质同样粗糙度、把高光完全打白。

## 主题配色

#eee9de / #c6ab84 / #ded0b8 / #909c83

## 可执行组件变体

- `sofa` → `cloud`
- `bed` → `soft`
- `chair` → `rounded`
- `tables` → `oval`
- `cabinet` → `fluted`
- `pendant` → `dome`
- `art` → `arches`

这些造型供初始选型参考；已建方案切换风格仅替换 CMF，保留家具造型、位置、朝向、尺寸、灯光和机位。换款是用户需求对应的独立家具替换动作。
