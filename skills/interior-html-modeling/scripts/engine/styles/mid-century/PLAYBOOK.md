# 中古暖木 / Mid-century Warmth

这是一套本包实现的可执行设计配方，不代表该风格的唯一历史定义。运行数据唯一来源：`catalog/styles.json` 中 `mid-century`。

## 主题

胡桃木、焦糖软包与有节奏的细支脚，温暖但不做一片棕色。

## 家具形状

外露木框沙发、木饰面床头、锥脚餐椅、圆角薄台面。

## 材料

胡桃木、焦糖细皮纹、燕麦织物、橄榄绿点缀、复古黄铜。

## 细节

斜向细脚、木框扶手、三球枝形灯、低柜与细拉手。

## 打灯

2850K暖光与自然光平衡；皮、木、铜的反射各有区分。

## 避免

避免把现代方盒只染棕色；避免全部表面高光清漆。

## 主题配色

#e8ddc8 / #ac774e / #a85c35 / #697655

## 可执行组件变体

- `sofa` → `timber`
- `bed` → `timber`
- `chair` → `timber`
- `tables` → `tapered`
- `cabinet` → `timber`
- `pendant` → `sputnik`
- `art` → `geometry`

切换风格可更换组内造型，保持房间功能、开口、组件 ID、位置、前向与包络尺寸。具体产品不声称品牌复刻。
