# 侘寂自然 / Wabi Sabi

这是一套本包实现的可执行设计配方，不代表该风格的唯一历史定义。运行数据唯一来源：`catalog/styles.json` 中 `wabi-sabi`。

## 主题

低重心、矿物肌理与不对称圆润块面；宁静而非破旧。

## 家具形状

低矮软包座体、厚木平台床、非正圆石几、柔和纸灯笼。

## 材料

石灰肌理、刷纹原木、粗麻、砂色石材；金属只作暗色连接件。

## 细节

圆润不规则边、低位收纳、单件素陶、少量艺术纹理。

## 打灯

2700K小范围暖光配柔和日光；避免用低曝光掩盖模型细节。

## 避免

避免人为破损、夸张污渍、满屋装饰和把所有轮廓都做圆。

## 主题配色

#d9cdbb / #a9997e / #bba98f / #77624d

## 可执行组件变体

- `sofa` → `low`
- `bed` → `platform`
- `chair` → `organic`
- `tables` → `organic`
- `cabinet` → `block`
- `pendant` → `paper`
- `art` → `earth`

这些造型供初始选型参考；已建方案切换风格仅替换 CMF，保留家具造型、位置、朝向、尺寸、灯光和机位。换款是用户需求对应的独立家具替换动作。
