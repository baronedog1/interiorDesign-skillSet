# 新中式 / Contemporary Chinese

这是一套本包实现的可执行设计配方，不代表该风格的唯一历史定义。运行数据唯一来源：`catalog/styles.json` 中 `new-chinese`。

## 主题

东方木构节奏与当代低密度陈设，木色和留白共同构成气质。

## 家具形状

外露方木框、细格栅靠背、木框床头、横撑餐桌与灯笼灯。

## 材料

深浅木饰面、米白亚麻、纸纤维灯罩、少量竹编和古铜。

## 细节

规则窄格栅、围合木扶手、托盘茶器、原创水墨抽象画。

## 打灯

3000K柔暖灯光，木格栅与白墙有清晰明暗；避免高饱和红光。

## 避免

避免堆砌符号、宫廷雕龙、高饱和红金和全屋厚重雕刻。

## 主题配色

#eee8dc / #8b6546 / #423127 / #6f7c71

## 可执行组件变体

- `sofa` → `lattice`
- `bed` → `lattice`
- `chair` → `lattice`
- `tables` → `trestle`
- `cabinet` → `lattice`
- `pendant` → `lantern`
- `art` → `ink`

这些造型供初始选型参考；已建方案切换风格仅替换 CMF，保留家具造型、位置、朝向、尺寸、灯光和机位。换款是用户需求对应的独立家具替换动作。
