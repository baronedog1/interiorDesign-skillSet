# 现代极简 / Modern Minimal

这是一套本包实现的可执行设计配方，不代表该风格的唯一历史定义。运行数据唯一来源：`catalog/styles.json` 中 `modern-minimal`。

## 主题

清晰平面、轻薄线条与灰白层次，以少量深色建立秩序。

## 家具形状

直线模块沙发、薄板床头、矩形石台、细金属桌脚和线性灯。

## 材料

暖灰漆面、烟灰木、灰石、细织物、拉丝银色金属。

## 细节

扁平无明拉手门片，浅阴缝，线性吊灯，几何艺术构图。

## 打灯

3500K中性偏暖；保留明暗对比，避免冷蓝大面积染色。

## 避免

避免复古车木脚、过量圆润泡芙造型、浮夸金属装饰。

## 主题配色

#e7e9e7 / #b9c0c0 / #53676d / #232b31

## 可执行组件变体

- `sofa` → `linear`
- `bed` → `panel`
- `chair` → `linear`
- `tables` → `rectilinear`
- `cabinet` → `flat`
- `pendant` → `linear`
- `art` → `geometry`

切换风格可更换组内造型，保持房间功能、开口、组件 ID、位置、前向与包络尺寸。具体产品不声称品牌复刻。
