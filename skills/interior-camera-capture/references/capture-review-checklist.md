# 原生截图复核清单

## 身份

- native model、camera plan、capture result、semantic frame、scene map 的后端和 SHA-256 完全一致。
- 候选和正式图都来自该后端原生相机。
- 每组只保留第一张合格主候选；只有主候选带机器失败码时，才允许再保留一张回退预览。

## 几何

- 主要空间中心射线垂直并命中背景墙。
- 偏航、俯仰、横滚、残差分别不超过 1°、0.25°、0.1°、0.25°。
- 四边留白均不少于 6%，左右差不超过 3%。
- 主角全部入画，近远尺度比不超过 1.18。
- 前景遮挡不超过 8%。

## 空间

- 第一眼能认出当前空间和功能主角。
- 开口后的相邻空间没有被无故隐藏。
- 每个隐藏对象都有原生 raycast 证据。
- 背景墙竖线竖直，水平分界水平。

## 双模式与语义

- 两张模式图相机、尺寸、模型版本一致。
- 槽位图只隐藏家具/柜体，JSON 槽位完整。
- 白模图显示同一组件。
- Entity ID、Room ID、Depth、房间、开口和槽位逐项对得上。
- 五项 Agent review 写明具体画面结论后才能标记 accepted。
