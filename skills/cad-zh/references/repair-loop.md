# 修复循环

生成、导出、检查、定位、快照、CAD Viewer 或文档验证失败时读取。

## 循环

1. 阅读失败命令的完整输出。
2. 对失败分类。
3. 只修改负责问题的最小源码或命令部分。
4. 重跑失败命令。
5. 重跑所有依赖该结果的验证。
6. 报告剩余风险或有意偏离。

## 失败类别与修复

### 源码导入或语法失败

常见原因：Python 语法错误、缺少 import、build123d 符号错误、函数不叫 `gen_step()`、预期函数外有副作用。

修复：更正 import/语法；确保 `gen_step()` 返回可导出 STEP 的 Shape/Compound；输出路径写在 CLI，不写进 `gen_step()`。

### 几何缺失或无效

常见原因：草图未闭合、减材轮廓不在目标内、零厚度、布尔失败、把构造几何当导出几何。

修复：闭合需要成面的轮廓；确认尺寸为正；通切工具必须真正贯穿；简化失败特征并逐步重建。

### 圆角或倒角失败

常见原因：半径/长度超过局部几何，选中细小或错误边，布尔生成复杂边拓扑。

修复：减小半径/长度；缩小边选择范围；把圆角放到最后；按特征意图拆分边组。

### 尺度或包围盒错误

常见原因：单位错、半径/直径混淆、拉伸方向/长度错误、原点与假设不一致、导入 STEP 单位异常。

修复：核对参数；检查 facts/planes；测关键范围；修正源码尺寸或导入处理。

### 特征缺失

常见原因：`Mode.ADD`/`Mode.SUBTRACT` 写反、轮廓不在目标内、盲切深度不足、前序操作后选择器变化。

修复：核对 Mode；通切增加长度；检查拓扑/平面；重新生成并测量特征引用。

### 选择器脆弱

常见原因：随意索引、布尔/圆角改变拓扑、相似面/边难以区分。

修复：按轴、平面、位置、法线或已检查引用选择；用 `refs --facts --planes --positioning` 重新发现；必要时增加构造基准或简化操作。

### 定位或 Joint 不匹配

常见原因：局部原点/基准错误、`AssemblyHelper` 固定/移动顺序相反、`.connect_to()` 移动了错误零件、Joint 轴反向、对称符号错误、参数变化后 `Location` 未重算、把世界坐标当成零件局部基准。

修复：先看 `refs --positioning`，再对相关选择器运行 `frame` 和 `align`；核对关系顺序、Joint 标签和 `joint_location`；按 `positioning.md` 做最小源码修正；从 Python 源重新生成并重跑检查。

### CAD Viewer 启动或链接失败

常见原因：Node/npm 不可用、Viewer 未构建或无法启动、URL 缺少项目绝对 `?dir=`、`file=` 不是绝对根目录内的相对路径。

修复：用相同项目绝对 `?dir=` 重跑 `$cad-viewer`，为每个产物使用正确 `file=`；每个请求文件返回一个链接。仍失败时报告启动错误，使用 CLI facts/measure 和快照替代。

### `scripts/snapshot` 失败

常见原因：目标路径错误/缺失，不是 STEP/STP 或同名 Python 生成器；相邻 Viewer GLB/拓扑缺失；渲染参数无效；Playwright 浏览器不可用。

修复：先生成 STEP，再对主 `.step`/`.stp` 快照；从单个 `view` 和简单参数开始，再增加 wireframe/section；按 `snapshot-review.md` 选择模式和验收包。若浏览器不可用，检查本设备共享 Playwright/Chrome 运行时映射。

## 修复后差异

修复可能影响无关几何时：

```bash
python scripts/inspect diff path/to/before.step path/to/after.step --planes
```
